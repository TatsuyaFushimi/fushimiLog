AI WEB WRITING ／ 資料要約

AI WEB WRITING

著者：ヒルトル・フィリップ太郎（株式会社ヒルトル）｜対象：中小企業経営者・個人事業主・フリーランス
この本が伝えること
生成AIを「優秀なアシスタントライター」として活用し、ウェブ集客・セールスに必要な文章を効率よく量産するためのノウハウ集。AIに全部丸投げするのではなく、人間がディレクターとしてAIに適切な指示を出すスタイルを解説。
SECTION 1 文章作成の5ステップ
  1. AIに学習させる「資料」を準備する（音声文字起こし、過去の記事など）
  2. プロンプト（指示文章）を作成してAIに伝える
  3. AIとチャットしながら原稿を書いてもらう
  4. 気に入らない箇所を伝えて書き直させる
  5. AIが書いた原稿を人間がチェック・加筆修正する
SECTION 2 推奨AIツール3選
ツール 強み 月額
ChatGPT（OpenAI） 画像生成・汎用性・最も有名。初心者向け 無料〜$20
Claude（Anthropic） 長文理解・文章執筆の質が高い。電子書籍・ブログに最適 無料〜$20
Gemini（Google） Google連携・SNS/広告文章が得意。セールスコピーに強い 無料〜2,900円

著者の使い分け：

  • 文章執筆 → Claude（長文処理が優秀）
  • セールスコピー・広告 → Gemini（くだけた文体が得意）
  • 汎用・画像生成 → ChatGPT

使用制限対策として、複数ツールの有料プランを契約することを推奨（合計1万円未満）

SECTION 3 9つのプロンプト
① マザープロンプト ★最重要
AIに自分のビジネスを理解させる「土台」となる文章。毎回使い回せる汎用設定。
6つの要素：
  1. 自己紹介 — 会社名・肩書き
  2. ミッション — 事業の目的・理念
  3. ターゲット — 理想の顧客像・悩み
  4. ベネフィット — 顧客が得られるメリット
  5. 商品・オファー — 無料→有料の導線
  6. 信念・価値観 — ブランドのトーン

作成のコツ：音声で話してそれを文字起こしする。過去の自己紹介動画も活用できる。

② 役割プロンプト
AIに「どんな専門家として書くか」を指示。
書き方の3ポイント：
  • ① 専門家の立場を明示（例：10年以上のキャリアを持つコピーライター）
  • ② 知識・経験・スキルを詳細に説明
  • ③ クライアントに提供できる成果を提示
③ 依頼プロンプト（指示プロンプト）
AIに具体的なタスクを依頼する文章。
基本構成：
#依頼 （メインの依頼を書く） ##作業1：（コンテンツの確認） ##作業2：（フレームワークの確認） ##作業3：（スワイプファイルの確認） → 各作業が終わったら理解できたか教えてください。 まだ実際の文章は書かないでください。
④ コンテンツプロンプト
AIに読み込ませる「学習素材」：
  • 過去の動画・音声の文字起こし
  • 過去に書いた電子書籍・ブログ記事
  • 商品紹介音声の文字起こし
  • 参考になる他社の記事
⑤ フレームワークプロンプト
文章の構成・骨格を指示する。

ブログ記事の構成例：導入 → 問題説明 → 解決策 → 実例 → ステップガイド → 注意事項 → Q&A → まとめ → CTA → 関連記事

セールスコピーの構成（PASTORフォーミュラ）：
文字 意味
PProblem（問題）
AAmplify（問題の増幅）
SStory & Solution（ストーリーと解決策）
TTransformation & Testimony（変革と証言）
OOffer（オファー）
RResponse（行動促進）
コツ：フレームワーク自体もAIに作ってもらうと楽。
⑥ スワイプファイルプロンプト
「参考にしてほしいお手本文章」をAIに提示する：
  • ブログ → 自分の過去の人気記事
  • セールス → 実際に売れた販売ページの文章
  • 広告 → 反応が良かった広告テキスト
自分の過去文章がない場合は他社のものを学習用として渡してOK（そのままコピーはNG）
⑦ ビフォーアフタープロンプト
商品使用前後の変化を描写（セールス系文章に必須）：
  • 顧客の悩み・課題（ビフォー）
  • 商品で解決された状態（アフター）
  • ギャップを際立たせ感情に訴える
⑧ マイルストーンプロンプト
目標達成までのステップを明示する。読者に具体的な行動イメージを持たせて説得力を上げる。
⑨ ペルソナプロンプト
典型的な顧客像を考えてもらうプロンプト。複数ペルソナに合わせたバリエーションのあるコンテンツを効率よく生成できる。
PRACTICE 実践事例（概要）
  1. AIにブログ記事を執筆してもらう方法 → 文字起こし + フレームワーク + スワイプファイルを用意してClaudeに指示
  2. AIにオプトインページの文章を書いてもらう方法 → マザープロンプト + ビフォーアフター + PASTORフォーミュラで高成約コピーを生成
  3. AIにセールスレターページの文章を書いてもらう方法 → 全プロンプトを組み合わせて完成度の高いセールスコピーを作成
SUMMARY まとめ
「AIはあくまで『副操縦士』。ゴールを示すのは人間。
AIを使いこなせるかどうかはあなた次第。」

  2. 明確なゴールを設定する
  3. 効果的なプロンプトを設計する
  4. 文章構成とライティングの基本スキルを持つ
  5. マーケティング・セールスライティングの知識を身につける
  6. AIの生成結果を評価・編集できる目を持つ
  7. 反復とテストで継続的に改善する
  8. 倫理的配慮とコンプライアンスを守る
