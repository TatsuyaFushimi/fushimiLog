AI活用 #14 — 実践資料

AIに「完成形」ではなく「素材」を作らせよう
素材化・資産化の発想でAI活用の幅を広げる

YouTubeで見た3Dプリンターの動画がきっかけ。BlenderとClaudeCodeで3Dモデル制作の新しいやり方を発見した話。
2026.04.08 ／ スライド#03の資料版
AIに「完成品を一発で作らせる」のではなく、「素材をパーツで作らせる」発想に変えるだけで、
再利用性が上がり、流用できる資産になる。
きっかけ — YouTubeで見た3Dプリンターの動画

YouTubeでプッカさんの動画を見ていたとき、「写真から3Dモデルが作れるツール」が紹介されていた。

そのとき「これ、アニメーション素材に使えるんじゃないか？」と直感した。前林さんに相談しながら、AI×Blenderで3Dモデルを作るという方向性が固まっていった。

今のAI活用でよくある使い方
  • 自動添削ツールで文章を一発で仕上げる
  • 画像生成AIでイラストを完成品として出力する
  • 動画生成AIで映像を一本まるごと作らせる
💡 共通する問題点

完成形を一発で生成しようとすると、ニュアンスがズレる・品質にバラつきが出る・修正が難しい・再利用できない、という壁に毎回ぶつかる。

発想の転換 — 「作る」から「素材を分解する」へ
今までの発想（完成品志向）
  • 「AIでアニメーションを作らせる」
  • ニュアンスが伝わらない
  • モデルが崩れる・動きが単調
  • オリジナリティが出にくい
  • 作り直しが一から必要
新しい発想（素材分解志向）
  • 「AIに素材（コード）を作らせる」
  • モデルと動きを別で管理
  • 再利用・組み合わせが簡単
  • 細かい調整は別ソフトで
  • 資産として蓄積できる
発想の転換ポイント
AIにお願いするのは「完成品」ではなく
「コード生成」→ 別ツールで動かす

Cursor / Claude Code内で完結させる必要はない。Pythonで使えるツール・ソフトは多い。AIにはコード生成だけお願いして、実行・調整は別ソフトで行うのが強い使い方。

やること2つ — 「作る」と「動かす」を分ける
① 3Dモデル・素材を作る（資産になる）

一度作ったモデルはファイルとして保存される。別のアニメーションにも流用できる。積み重なるほど価値が増す。

② アニメーションさせる（コードで細かく指定）

モデルの動きはコードで指定。日本語で「左から右にフワっと飛んでくる」と伝えるだけでBlenderのコードを生成してくれる。

⚠️ 課題2点：①キャラクター・3Dモデルの精度 / ②アニメーション作成の難易度。この2点を解決するのがClaude CodeとBlenderの組み合わせ。
実際の手順 — 3ステップで3Dモデルを作る
1
白黒の濃淡イラストを用意する

Nanobananaなどのツールで、陰影のある白黒イラストを用意する。立体化しやすい状態（表・裏の2面）に整えておく。シンプルなほど精度が上がる。

2
画像からClaude CodeでBlender用コードを生成

画像をClaude Codeに渡して「この画像をBlenderで3D化するコードを書いて」と伝えるだけ。Blenderで実行できるPythonコードが出力される。

3
Blenderで確認・微調整してモデル完成

生成されたコードをBlenderで実行し、モデルを確認。細かい調整はBlender上のGUI操作か、再度Claude Codeに指示して修正コードを生成。

💡 「この画像をBlenderで3D化するコードを書いて」— このひと言だけでClaude Codeがコードを生成してくれる。専門知識は不要。
動きの付け方 — Blender内で日本語指示

3Dモデルができたら、次は動きを付ける。モデルとアニメーションは別ファイル・別作業として管理するのがポイント。

指示の例
実際にClaude Codeに伝えた指示

「左から右にフワっと飛んでくる動きを作って」「着地したときに少しバウンドさせて」— このレベルの日本語でBlender用のアニメーションコードが生成される。

動きの種類指示の例Blenderでの実装
移動 「左から右へフワっと飛んでくる」 Location キーフレーム + イージング
回転 「コインが転がって倒れる」 Rotation キーフレーム
バウンド 「着地後に少し跳ねる」 Bounce カーブ設定
フェード 「だんだん透明になって消える」 Alpha キーフレーム
素材化・資産化のメリット

一度作ったものがその場限りで終わらない。これが素材化発想の最大の強み。

同じモデルで別の動きができる
  • じっちゃまモデルを作ったら → 歩く・飛ぶ・回転など何通りでも
  • アニメーションだけ差し替えれば再利用できる
  • 撮り直し・描き直しがいらない
同じ動きで別モデルに使える
  • 「フワっと飛んでくる」動きを別キャラに適用
  • 動きのコードをライブラリ化できる
  • 制作スピードが回を重ねるごとに上がる
3Dモデルはアニメーション以外にも使える
  • 動画素材 — サムネイル・OPアニメーション・Bロール
  • 他モデルへの流用 — 同じリグ・同じ動きをベースに派生キャラを作れる
  • 3Dプリント — データをそのまま3Dプリンターに送れる
Claude Codeとの組み合わせが強い理由
Claude Codeはコード生成が圧倒的に強い

画像や動画を直接生成するAIツールと異なり、Claude Codeは「コードを書く」ことに特化している。Blender（Python）・AfterEffects（ExtendScript）・Premiere Pro（CEP）など、コードで制御できるソフトは全部使える。

アプローチできること課題
AIで直接生成 一発で動画・画像が出る ニュアンスがズレる、修正が難しい、再利用できない
Claude Code × 外部ソフト コードで細かく制御できる ソフトの基本操作は必要（Blender・AE等）
💡 Claude Code をある程度使っている人なら十分試せる内容。Blenderは無料で使える。
まとめ
01 AIは完成品を作るためだけでない

素材を作らせる使い方が強い。モデルと動きを分けて考えると再利用しやすくなる。

02 Claude Codeはコード生成を軸に使うと特に強い

Blender・AE・Premiere Proなど、コードで操作できるソフトとの組み合わせが最大の武器。

03 使う場所を変えるだけでAI活用の幅は広がる

ClaudeCodeの中だけで完結させる必要はない。外部ソフトに連携させることで、できることが格段に増える。

04 作るたびに資産が積み上がる

素材として残すことで、次回以降の制作コストが下がる。一度の手間が長期的なリターンになる。

今日のTAKEAWAY

制作物は「使い捨て」から「資産」になる
